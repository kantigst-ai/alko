Настройки Atelier Bar

Все ключи и токены хранятся исключительно в вашем браузере (localStorage)

Режим работы: Если API-ключ указан, генератор обращается к выбранной языковой модели с системным промптом шеф-миксолога. Если ключ не задан, автоматически работает встроенный алгоритмический миксолог по правилу золотого сечения коктейлей.
Инструкция по настройке Fine-grained PAT:
  1. Перейдите в GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Выберите Only select repositories и укажите ваш репозиторий для бара.
  3. В разделе Repository permissions установите Contents: Read and write.
  4. Скопируйте сгенерированный токен (github_pat_... или ghp_...) в поле ниже.

Записать авторский рецепт

Рецепт сохраняется локально в браузере (отправка в GitHub — по кнопке «Push в GitHub»)

Удалить рецепт из коллекции?

Рецепт будет удален из локального хранилища браузера. Чтобы обновить файл recipes.json в репозитории, нажмите кнопку «Push в GitHub».
